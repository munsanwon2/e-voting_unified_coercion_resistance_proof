
# e-voting_unified_coercion_resistance_proof

**Supplementary Proofs for "SoK: A Unified Framework for Analyzing Coercion Resistance in Electronic Voting"**

This repository contains supplementary proofs and analyses supporting the protocol classifications presented in Table 1 of the paper.

## Proof Files

- **[Syntax_proof.pdf](Syntax_proof.pdf)**: Demonstrates how each e-voting protocol considered in the paper can be represented using our unified e-voting syntax.

- **[verifiability_proof.pdf](verifiability_proof.pdf)**: Provides protocol-specific analyses supporting the verifiability classifications (No, Weak, or Strong) reported in Table 1.

- **[ballot_privacy_proof.pdf](ballot_privacy_proof.pdf)**: Provides protocol-specific ballot-privacy analyses under the assumptions stated in Table 1.

- **[coercion-resistance_proof.pdf](coercion-resistance_proof.pdf)**: Establishes coercion resistance for the classified coercer capabilities reported for each protocol in Table 1, including the corresponding counterstrategies and security arguments.

- **[coercion-resistance_maximality_proof.pdf](coercion-resistance_maximality_proof.pdf)**: Establishes the maximality of the coercer capabilities by analyzing stronger adversarial settings and providing protocol-specific impossibility results.
